# Aerospace Portfolio Code

MATLAB models I wrote for my two University of Texas at Arlington senior design projects (2026). Each folder has its own README explaining what the model does, how it was verified, and how to run it.

| Project | Models | Write-up |
| --- | --- | --- |
| [Supersonic Business Jet](supersonic-business-jet/) | Balanced field length (14 CFR Part 25), Roskam program cost | [Portfolio page](https://sites.google.com/view/steven-handrick-aerospace-port/home) |
| [Dream Chaser](dream-chaser/) | Vulcan VC4L ascent, mission weight ratio, glide range, TransCost life-cycle cost | [Portfolio page](https://sites.google.com/view/steven-handrick-aerospace-port/home) |

These are academic conceptual-design models. Inputs such as aerodynamics, propulsion and weights came from teammates on each project; the code here is my own work.

Requires MATLAB (base product; no toolboxes needed for these scripts as written).
